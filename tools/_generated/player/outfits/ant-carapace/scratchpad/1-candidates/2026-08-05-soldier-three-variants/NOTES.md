# 2026-08-05 — three variants of the SOLDIER-PLATE design

> Owner pick (2026-08-05): the first version, the soldier carapace — next step, three variants of it.

**One paid call.** The chosen option-1 figure was cropped out and passed as a **second reference**
(`_reference_option1.png`), so these vary the design rather than inventing three new ones — same helm,
same dark red-brown chitin, same mandible jaw guards flanking the visor.

Open `REVIEW_large_and_game_size.png`; the bottom row is each at real game size on grass.

| | variant | the silhouette | width |
|---|---|---|---|
| **1** | **heavy pauldrons** | very broad blocky shoulders flaring past the body — a tank | 478px |
| **2** | **long tusks** | the mandible guards sweep far forward like curved tusks, the biggest feature | 492px |
| **3** | **high crest** | a tall ridge crest over the helm, trim body and close shoulders | 274px |

## Checks

- **height spread 7.4%** — same as the three-options run (7.0%), inside the roster range (0.5-10.6%)
- **baselines 950 / 947 / 948** — aligned
- **stray magenta: 0** on all three. The previous run had 665 on its option 3, so this is clean
- all three keep the full helm with a visor slit, which is the armour-set convention

**Variant 3 is half the width of the other two** (274 vs 478/492). That is the design doing what was
asked — "tighter trimmer body and close-fitting shoulders" — but it is worth seeing at game size before
picking, because a narrow figure reads as a different weight class from the rest of the armour tier.
