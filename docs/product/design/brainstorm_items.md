# BugFarmer item brainstorm (for review)

A wide net of things we could add — to keep the world rich and the player un-bored. Decorations aren't
just pretty: **placed decorations grant passive farm bonuses** (with diminishing returns per duplicate +
a cap, `game_design.md §11.5`), so variety + a value/rarity ladder is a real mechanic. Tag = likely bonus
hook. Cut freely; this is a menu, not a commitment. (Surface/village leans pretty; underground leans
mining; desert leans dry/utility.)
