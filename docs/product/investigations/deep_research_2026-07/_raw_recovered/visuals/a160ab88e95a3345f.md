# BREAKING mechanic — end-to-end trace (so DIG can mirror it)

Important upfront correction: **there is no "reset if you stop hitting" in the current code.** Breaking progress persists indefinitely server-side and only resets when a *different* player hits the same cell. Details in section 3. Everything else you described exists.

Also note: a **shovel + `Dig` verb already exists** today, but it's a *single instant* action (grant a block, revert to dirt) via the farming tool path — not a multi-hit break. That's the thing you're replacing. Details in section 5.

**Occupant-specific (do NOT reuse directly — needs a ground-cell analog):**
