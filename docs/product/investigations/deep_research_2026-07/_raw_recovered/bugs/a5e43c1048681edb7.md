**Cavern types + spatial logic** (DECISION — caves.md + proven scene vocabulary)
- `carve_cavern(shape=blob|long/gallery|rocky/jagged|lobed, size, seed)` — never clean circles; **rocky** auto-leaves interior rock columns (the "stalagmite" stand-in). `carve_chamber` unions 2-3 offset blobs for explored caverns.
- **Isolation is the point in a mining zone** — caverns are NOT tunnel-linked; player mines to them. Only man-made rail shafts are pre-dug. Don't auto-connect for walkability.
- Tunnels: natural MEANDER (never straight >4 cells); man-made STRAIGHT only if carrying `mine_rail` + `mine_support`. Contrast both in-scene.
- `cave_pool(cx,cy,size,carved,seed)` in ~half the caverns, off-centre, bayed waterline, never an ellipse; keep water OFF the rail tunnel.
- Proven build order in scene_underground_caverns.py: carve caverns → straight rail tunnel → natural burrows → `cave_pool` → `fill_solid` ore → wall-embedded quartz/`torch_wall` (minerals only in rock faces, never floor) → fungus clumps in light-pools against walls → sparse earthtone litter (`rubble`/`cave_moss`/`bone_pile`) → free-floating fauna sprites → spawn off-rail.
