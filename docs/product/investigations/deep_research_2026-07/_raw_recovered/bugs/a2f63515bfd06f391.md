# CALMING / SUBDUAL — the true design-of-record vs. what's built

## Bottom line up front

The design docs are unambiguous: **smoke/calm is a GENERAL subdual mechanic, not bee-only** — and the doc even names the **centipede** as the flagship smoker target ("subduing comes with the smoker"). The first implementation is a **server-only, nest-only** slice (`handleSmoker` calms *nest* defenders) that is (a) not reachable from the current client, (b) has no item backing it, and (c) touches only ONE of the three aggression paths and NONE of catchability. The `catch_condition`/`condition_*` schema is a **dead stub** inherited from an older full-meter spec. `calm_spray` is consumed nowhere.

## (d) Gap list — what a GENERAL calming system must cover to match the docs

**Schema already waiting (reuse, don't re-add):**
- `species.CatchCondition / ConditionThreshold / ConditionDecay / ConditionTools map[string]float32` (`species.go:53-56`) — the intended "tool → meter-fill rate" map is `ConditionTools`.
- `SwarmState.ConditionValue` + `IndividualBugState.ConditionValue` (0-100 meter) — allocated, never used.
- `nest.SmokedUntilTick` pattern (`nest.go:24`) — a working per-entity "calmed-until-tick" precedent to generalize from nest to swarm.
- `calm_spray` item with `reach:3.0, effect:"calm"` + client `EntityDatabase.Effect` parse — data plumbed, just unconsumed.
- Message vocabulary designed in `bugs_new.md` (`MeterDeltaMessage`, `SwarmMeterUpdateMessage`, `CatchResultMessage.Reason "not_subdued"`) — not yet implemented but specified.

**Gaps a faithful general system must close:**

1. **Generalize "calmed" from nests to swarms.** Today smoke lives only on `NestState.SmokedUntilTick` and only mutes nest-defend. Docs want smoke/calm to lower agitation on *any* swarm (centipede especially). Needs a per-swarm calm/condition state (the `ConditionValue` meter or a `CalmedUntilTick`) checked in all three aggression funnels.

2. **Cover ambient contact sting** (`checkBugAttacks`) — currently smoke does nothing to a wasp you stand in. A calmed swarm should skip/soften this.

3. **Cover the centipede ActionState lunge** (`centipede.go` windup/surge) — the doc's headline smoker target has zero calm hook; a calmed centipede should not wind up / should abort the surge.

4. **Wire catchability to condition** (`handleCatchBug`, plug-in point right after the net-tier gate, `match.go:2448`): honor `catch_condition` ("always" vs "calm"/"weakened"), compare `ConditionValue` to `ConditionThreshold`, reject with a "not_subdued" reason. This is what makes `trap_only`/centipede a *subdue-then-take* loop instead of "far too big for any net."

5. **Build a consumable-use verb.** `calm_spray` (and future `smoke_bomb`/`chill_canister`/`stun_rod`) need an actual use path: an OpCode + server handler that applies `effect:"calm"` in a radius, and a client route (neither `PlayerInputRouter` nor `ToolUseController` handles `category:"consumable"` today).

6. **Make the smoker itself reachable.** Add a `smoker`/`bee_smoker` item (`tool_type:"smoker"`, reconcile the catalog `bee_smoker` vs code `smoker` id), and add a `case "smoker":` to `PlayerInputRouter.cs:96` routing to a tool-use send. Right now the whole server handler is orphaned.

7. **Tools × effect taxonomy** the docs assume but code lacks: calm (smoke), slow (`chill_canister`), stun (`stun_rod`) as distinct condition types feeding one meter (the `bugs_new.md` calm/agitation/panic model, or a single `ConditionValue` with tool-specific fill via `ConditionTools`). "Using the wrong tool can agitate a swarm" (§7.3) implies negative deltas too.

8. **Tiers & set bonuses** (data-side): `bee_smoker` ≥3 tiers (D12), `subdue+` armor stat filling the meter faster, Entomologist set boosting calm-spray/`catch_*`, "some bees hostile" — all reference the same meter, so the meter must exist first.

9. **Latent inert flags:** `stings_only_defending` and `attack_is_sting` are set on **no** live species; a general calm design should decide each species' provoke model (bee = gentle-until-defending; wasp = ambient; centipede = lunge) and populate these — and note there is **no bee species yet at all**, so "the vast majority of bugs can be calmed" currently means wasp (partially) + centipede (not at all), since flies/butterflies/millipede/beetle are already harmless.
