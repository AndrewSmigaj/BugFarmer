## 3. Reusable underground build patterns

### `tools/zonegen/features/cave.py` signatures
- `carve_tunnel(b, start, end, *, style="natural", width=2, seed=0, wobble=0.55)` → open-cell set. `natural` = momentum + wobble meander, width jitters 1-3; `straight` = clean corridor (pair with rail/supports). `:40-72`
- `carve_cavern(b, cx, cy, *, shape="blob", size=8, seed=0)` → open cells. Radial mask blended with fBm noise, thresholded, CA-smoothed (never a clean circle). shapes: `blob`, `rocky` (leaves interior rock columns), `lobed`, `long` (delegates to a fat meander tunnel). `:75-111`
- `carve_chamber(b, cx, cy, size, *, seed=0)` → union of 2-3 offset `carve_cavern` blobs along a random axis (kidney/peanut voids); use for explored rooms. `:132-148`
- `cave_pool(b, cx, cy, size, carved, *, seed=0, shore=True)` → water cells. Irregular bayed waterline clipped to a cavern's carved cells; `water_deep` core → `water_shallow` rim → shoreline re-derived as damp `mud` bank + scattered rubble/moss. Seat off-center. (`place_pool` `:114-129` is the deprecated single-ellipse version.) `:151-226`
- `fill_solid(b, carved, table, *, seed=0, substrate=None)` → fills every non-carved cell with a block. Ore = random-walk VEINS whose starts are spread on a jittered grid per band (even coverage, no dead walls); `pockets` = clusters; rest = base. `substrate(x,y)->block_id` overrides base per cell (paints the dirt↔stone depth gradient). `table = {'base':id, 'veins':[(id,count,lo,hi[,band])], 'pockets':[(id,count,radius,zone)]}`; bands `surface|top|mid|bottom|deep|any`, `deep` = bottom fifth. `:282-320`, band ranges `:249-253`, vein walk `:229-246`.

### Full-zone composition recipe (`zone_underground_passages.py`, worked-example `scene_underground_caverns.py`)
1. `ZoneBuilder(..., base_tile="cave_floor", biome="cave")` (`:66`; caves.md:3-5).
2. Noise fields for gradient/seam warps (`:68-73`).
3. `substrate(x,y)` + `ground_tile(x,y)` = the **Terraria depth model**: dirt at surface + SW ant seam, fuzzy dirt↔stone transition, solid stone deep; floor tile shifts dirt→cave_floor→`mud` deep (`:77-103`).
4. **Paint ground**: grass surface above `surf_y`, floor-by-depth below (`:106-118`); seed `carved` from the grass set (`:119`).
5. **Carve**: mouth + straight rail shaft + hub (`:122-124`) → **isolated** caverns via `carve_chamber`, ~half getting a `cave_pool` (`:130-151`) → ant burrows out the west edge (`:154-158`).
6. **ONE** `fill_solid(carved, ORE, substrate=substrate)` over all remaining rock (`:163`).
7. `mine_rail` down the shaft centerline + `torch_wall` every 6 rows on the walls (`:166-175`); camps place props only (`:178-179`).
8. **FLOOR_BAG dressing** (`:61-62` = rubble, cave_moss, mushroom_glow, mushroom_blue, mushroom_brown, bone_pile, quartz_block, crystal_small): glow fungus clumps around random centers + earthtone scatter, ~10% of cave cells (`:182-196`); cliff-base rubble (`:199-205`); then `bug_spawning` (`:211-235`).
