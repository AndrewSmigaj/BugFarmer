This is the sole S→C reply for buy/sell — includes `coins`.

**JsonUtility nested-list precedent — YES, a nested line class needs `[Serializable]`.** Unity's `JsonUtility` only serializes fields of `[Serializable]` types, and arrays/`List<T>` of a custom class require that class to be `[Serializable]`. Existing precedent: `ContainerUpdateMessage` (`Networking/ContainerMessages.cs:51-64`) has `public InventorySlot[] slots;` (L56), where `InventorySlot` is declared `[Serializable]` in `InventoryMessages.cs:27-28`:
```csharp
[Serializable]
public class InventorySlot { public string item_id; public int count; ... }
```
So a new `List<ShopSellLine>` (or `ShopSellLine[]`) field on a batch message would require `[Serializable]` on `ShopSellLine`. Caveat: `InventorySlot` also carries `public Dictionary<string,int> metadata;` (L30) — `JsonUtility` does **not** serialize `Dictionary`, so keep any new line DTO to plain fields (string/int) to be JsonUtility-safe. All message classes in `NetworkMessages.cs`/`InventoryMessages.cs`/`ContainerMessages.cs` are uniformly `[Serializable]` (e.g. NetworkMessages.cs L95-98 `EntityData[] entities`; L247-254 arrays).
