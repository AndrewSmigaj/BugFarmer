# Skill-check minigames in farming/processing games — research findings

## Key upfront finding
The **processing/crafting stations** in nearly every farming sim in this list are **passive timers, not minigames**. The real skill-check minigames in these games are concentrated in **fishing** (a catch-bar or click-to-stop timing check) and in **cooking** (Dave the Diver's Cooking-Mama-style contests). This is the single most important design signal: the genre almost never gates *machine processing* (kegs, furnaces, looms) behind a dexterity check — it gates *fishing* and *special cooking* instead.

## Corroborated by search (not full-fetched, lower confidence — flagged as such)
- **Graveyard Keeper crafting** (Steam guide + gamerant snippets): **not a dexterity minigame** — you press Craft and **hold F** to run the station; you must sit next to it while it works. Quality is a **star system (white → up to red/gold star)** driven by *ingredient quality + fertilizer/tech*, shown as a **probability table** of hitting each quality tier — i.e., a stats/RNG check, not a timing check. Higher-quality tiers can only be crafted **one at a time**. Downside players raise: sitting and waiting per item is tedious.
- **My Time at Portia** (fandom/trueachievements snippets): processing = **fueled passive timers** (Stone Furnace: 20-wood cap, 1 hr fuel/wood; production halts when fuel runs out). Assembly Station has a **45-min-of-game-time** passive build. A popular Steam thread is literally titled *"Why does everything have a timer? Feels like mobile game"* — the core criticism of timer-gated processing.
- **My Time at Sandrock** (fandom): Assembly Station crafts **instantly** once you manually feed the prompted materials into a placed blueprint; level-3 Advanced station adds **auto-assemble**. Manual material-loading is the only "interaction," not a skill check. Reviewers separately call out Sandrock's *many* minigames (whack-a-mole, rhythm, sled racing) as "highly involved, mediocre" — but those are events, **not** at processing stations.
- **Coral Island** (Nexus/guides): processing machines = **passive timers**; the endgame "Auto Chest" removes even the manual loading. Popular mods = "Instant Processing" / "Faster Processing" (players want *less* waiting, not a minigame).

## Synthesis / design takeaways for Bug Farmer

1. **The genre convention is: processing stations = passive timers, not minigames.** Stardew, Portia, Coral Island, Sandrock, Graveyard Keeper all make machine output a wait, and the mod ecosystems (Coral Island "Instant Processing," Sun Haven "No Time For Fishing," Portia's "mobile-game timer" complaint thread) show players actively resent *forced* per-item interaction. If you add a minigame to *every* processing action, expect the Portia backlash: "feels like a mobile game."

2. **Where skill-checks DO live, they follow two archetypes:**
   - **The catch-bar / keep-in-zone** (Stardew): one-button feathered *hold*, continuous meter fill/drain, difficulty via erratic target motion, mastery via a growing tolerance zone. Reward = the catch + a "Perfect" quality/score flag.
   - **The click-to-stop timing gate** (Sun Haven): a single well-timed click on a moving marker, nested "good / perfect" zones, rarity shrinks the zone. Reward = a flat **perfect bonus (+30% XP)**. This is the cheapest to build and the least fatiguing per-rep — the best fit for a *short* skill check that repeats often.

3. **Reward model that avoids punishing failure:** the successful designs give a **bonus on perfect, no real penalty on "just okay."** Sun Haven = +30% XP for the sweet spot (miss it, you still catch). Dave the Diver contests give **partial-credit scores** (92 despite a fumbled step). Stardew's "Perfect" is mostly a quality/scoring flag. None of them make a normal-skill failure destroy the item. For a processing minigame this is the key lesson: **perfect = speed/quality/yield bonus; average = normal result; you don't lose the input.**

4. **Keep it short and don't force it every time.** Dave the Diver's cook-offs are the *most minigame-y* processing analog and also the **most criticized** ("artificial difficulty spike," "poorly implemented," finicky rotation on controller, 4 failed evenings). Notably they are **occasional contest events**, not the everyday cooking loop — everyday cooking is automatic. The pattern that works: **routine processing is passive/automatic; the skill minigame is an opt-in, occasional, bonus-bearing event**, and even then keep the input scheme simple (avoid the circular-rotation-on-controller trap that Dave the Diver got dinged for).

5. **"Skippable once mastered" is valued.** Every game here either auto-completes at high tier (Sandrock auto-assemble, Coral Island Auto Chest, Portia auto-workstation) or has a mod to remove the minigame (Sun Haven). Build an automation/skip path for late game from the start.

### Verbs actually observed (for your VERB palette)
Reel/keep-in-box (Stardew), click-to-stop (Sun Haven), chop / coat-with-starch / stir / mix / rotate (Dave the Diver). Notably absent from *processing* stations across the whole set: pan, mash, thread, spin as active skill checks — those would be **novel** to the genre if you build them, but the evidence says gate them as *bonus/perfect* checks, not as mandatory per-item taxes.
