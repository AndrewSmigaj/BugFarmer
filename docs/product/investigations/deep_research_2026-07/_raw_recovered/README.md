# Raw recovered research (2026-07-10 overnight run)

These are **raw transcript extracts** — the assistant-authored research (source tables, deep-read
findings, syntheses) recovered from the overnight research agents' transcript files after the run
hit the session limit before the agents could write their final polished documents.

**Why they exist:** the overnight research was launched with too wide an agent fan-out; the agents
did the research (deep-read sources, built source tables) but most died on the session limit before
writing their target doc, returning only an error. The research itself survived in the transcripts;
this folder is that research, extracted and made permanent so it is never lost again. See the
`no-wide-agent-fanout` memory for the rule this violated.

**Status:** RAW. Each file is one agent's working transcript text (may include false starts, tool
narration, and duplication). They are the *source material* for the clean per-topic docs in
`../combat/`, `../bugs/`, `../station_minigames/`, `../visuals/`. Filenames are agent IDs, not topics.

- `combat/` — melee enemy AI, swarm/group AI, threat directors + attack-token pacing, telegraphing.
- `bugs/` — per-species behavior research (spiders, hornet, scorpion, centipede, pollinators, etc.).
- `minigames/` — crafting-station minigame taxonomy + per-station proposals.
- `visuals/` — Unity 6.2 URP-2D techniques, asset packs, art-direction reference (some files may be
  mis-bucketed by the keyword sort; treat as a starting pile, not a clean split).
